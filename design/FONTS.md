# FONTS.md — Typeface Specification

Values only. Usage rules (when to use which family, emphasis policy) live in
`manuscript/STYLE.md`. The single source of truth for font loading is
`design/tokens.css`; the file inventory is `design/fonts/` (+ `design/fonts/README.md`
for sources and regeneration).

## 1. Families

| Role | Family | Files (design/fonts/) | Weights loaded |
| --- | --- | --- | --- |
| Display / headings | Barlow Condensed | `BarlowCondensed-{Regular,Medium,SemiBold,Bold}.woff2` + `.ttf` | 400, 500, 600, 700 |
| Body | Minion Pro | `minion-pro-webfont/*.woff` (web), `minion-pro/*.otf` (LaTeX) | 400 (+italic), 700 (+italic) |
| Code / mono | JetBrains Mono | `JetBrainsMono-{Regular,Medium,Bold}.woff2`, `JetBrainsMono.ttf` | 400, 500, 700 |
| Math | KaTeX fonts | bundled by the build | — |

No fourth family without updating this file, `tokens.css`, and the font pipeline.

## 2. Print type scale (authoritative)

| Element | Family | Weight / style | Size / leading | Notes |
| --- | --- | --- | --- | --- |
| Book title | Barlow Condensed | Bold | 28 pt / 32 pt | Centered, +5 % tracking |
| Chapter title (H1) | Barlow Condensed | Bold | 20 pt / 24 pt | Left; 18 pt space after |
| Section title (H2) | Barlow Condensed | SemiBold | 14 pt / 17 pt | 12 pt space before |
| Subsection (H3) | Barlow Condensed | Medium / Italic | 11 pt / 14 pt | 8 pt space before |
| Body paragraphs | Minion Pro | Regular | 9.5 pt / 13.5 pt (142 %) | Justified, tight hyphenation |
| Code blocks | JetBrains Mono | Regular | 8.0 pt / 10.5 pt (131 %) | Flush left, tab-size 2 |
| Inline code | JetBrains Mono | Regular | 8.5 pt | `--paper-deep` background |
| Table text / captions | Barlow Condensed | Regular / Medium | 8.0 pt / 10.0 pt | Small-caps headers |
| Footnotes | Minion Pro | Regular | 7.5 pt / 10.0 pt | Left, ragged right |

Large display titles tighten tracking: `letter-spacing: -0.015em`.

## 3. Per-medium body and code sizes

| Element | Screen (HTML) | Print (PDF) | EPUB |
| --- | --- | --- | --- |
| Body size | 17 px | 10.5 pt | 1 em |
| Body leading | 1.65 | 1.5 | 1.55 |
| Code size | 0.88 rem | 7.6 pt | 0.82 em |

Measure: `--measure: 68ch` for single-column text (in two-column print, the column
width is the measure). Paragraph indent: `--paragraph-indent: 1.2em`; the first
paragraph after a heading, figure, table, code block, display equation, note, or list
is not indented.

## 5. Fallback stacks

| Role | Stack |
| --- | --- |
| Display | `"Barlow Condensed", "Arial Narrow", system-ui, sans-serif` |
| Body | `"Minion Pro", "Segoe UI", system-ui, sans-serif` |
| Mono | `"JetBrains Mono", ui-monospace, monospace` |
| Math | `"KaTeX_Main", "Latin Modern Math", "STIX Two Math", serif` |

Fallbacks exist for development and for EPUB systems that ignore embedded fonts; they
are not a license to use another family in source.

## 6. File management

- WOFF2 → HTML/PDF. TTF → embedded in EPUB. OTF (`minion-pro/`) → LuaLaTeX via
  `fontspec` (see `ARCHITECTURE.md` §6).
- Font binaries are generated by `bun run prepare` and are not committed.
- Math is typeset by KaTeX with its own fonts; no body family is used for math.
