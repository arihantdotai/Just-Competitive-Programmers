# FONTS.md — Typeface Specification

Values only. Usage rules (when to use which family, emphasis policy) live in
`manuscript/_STYLE.md`. The single source of truth for font loading is
`design/css/tokens.css`; the file inventory is `design/fonts/` (+
`design/fonts/README.md` for sources and regeneration).

## 1. Families

| Role | Family | Files (design/fonts/) | Weights loaded |
| --- | --- | --- | --- |
| Display / headings | Barlow Condensed | `BarlowCondensed-{Regular,Medium,SemiBold,Bold}.woff2` + `.ttf` | 400, 500, 600, 700 |
| Body | Minion Pro | `minion-pro-webfont/*.woff` (web), `minion-pro/*.otf` (LaTeX) | 400 (+italic), 700 (+italic) |
| Code / mono | JetBrains Mono | `JetBrainsMono-{Regular,Medium,Bold}.woff2`, `JetBrainsMono.ttf` | 400, 500, 700 |
| Math | KaTeX fonts | bundled by the build | — |

Barlow Condensed plays the role of the O'Reilly display face (Myriad Pro Condensed)
in this book; JetBrains Mono is the monospace face. No fourth family without updating
this file, `design/css/tokens.css`, and the font pipeline.

## 2. Print type scale (authoritative)

| Element | Family | Weight / style | Size / leading | Notes |
| --- | --- | --- | --- | --- |
| Chapter number & title | Barlow Condensed | Bold | 18–24 pt | `CHAPTER N` label above the title |
| Epigraph | Minion Pro | Italic | 9–9.5 pt | Beneath the title, em-dash attribution |
| A-level heading (H1, `##`) | Barlow Condensed | Bold / SemiBold | 14–16 pt | Title case; no inline code |
| B-level heading (H2, `###`) | Barlow Condensed | Bold / SemiBold | 12–13 pt | Title case |
| C-level heading (H3, `####`) | Barlow Condensed | Bold / Italic | 10.5–11 pt | Sentence case |
| Body paragraphs | Minion Pro | Regular | 10 pt / 12.5 pt | Justified, hyphenated |
| Code blocks / listings | JetBrains Mono | Regular | 8.5–9 pt | Left; 81–85 characters max |
| Tables & captions | Barlow Condensed / Minion Pro | Regular / Medium | 8.5–9 pt | `Table 1-1`, `Figure 2-1` |
| Running heads | Barlow Condensed | Regular / Medium | 8–8.5 pt | Muted; uppercase |
| References | Minion Pro | Regular | 8.5–9 pt | Numbered `[1]` per chapter |

Large display titles tighten tracking: `letter-spacing: -0.015em`.

## 3. Per-medium body and code sizes

| Element | Screen (HTML / website) | Print (PDF) | EPUB |
| --- | --- | --- | --- |
| Body size | 17 px | 10 pt | 1 em |
| Body leading | 1.65 | 1.25 (12.5 pt) | 1.55 |
| Code size | 0.88 rem | 8.5 pt | 0.82 em |

Measure: `--measure: 68ch` for the single column. Paragraph indent:
`--paragraph-indent: 1.2em`; the first paragraph after a heading, figure, table, code
block, display equation, note, or list is not indented.

## 5. Fallback stacks

| Role | Stack |
| --- | --- |
| Display | `"Barlow Condensed", "Arial Narrow", system-ui, sans-serif` |
| Body | `"Minion Pro", "Segoe UI", system-ui, sans-serif` |
| Mono | `"JetBrains Mono", ui-monospace, monospace` |
| Math | `"KaTeX_Main", "Latin Modern Math", "STIX Two Math", serif` |

Fallbacks exist for development and for EPUB systems that ignore embedded fonts; they
are not a license to use another family in source.

## 6. File management

- WOFF2 → HTML/website/PDF. TTF → embedded in EPUB. OTF (`minion-pro/`) → LuaLaTeX via
  `fontspec` (see `ARCHITECTURE.md` §6).
- Font binaries are generated by `bun run prepare` and are not committed.
- Math is typeset by KaTeX with its own fonts; no body family is used for math.
