# DESIGN.md — Design Index & Layout Specification

The design system is split into focused spec files. This file is the index plus the
layout, structure, and numbering spec. **Usage guidance ("how to write") lives in
`manuscript/STYLE.md`; the files here state facts and values.**

| File | Contents |
| --- | --- |
| `FONTS.md` | Families, files, weights, the full type scale with values, fallbacks |
| `COLOR.md` | All color tokens with values, diagram palette, dark-mode note |
| `CALLOUTS.md` | The seven note types and their rendering spec |
| `FOOTNOTES.md` | Footnote/citation placement, values, per-output behavior |
| `tokens.css` | Single source of truth for every value loaded at runtime |
| `book.css` / `print.css` / `epub.css` | Implementation (screen, print, EPUB) |
| `fonts/` | Font binaries (generated by `bun run prepare`; see `fonts/README.md`) |

Scope note: layout facts below describe the current print pipeline (Paged.js) that
still feeds the EPUB. Under the LaTeX migration (`ARCHITECTURE.md`), the LaTeX
preamble reproduces the same typographic values from `FONTS.md`, `COLOR.md`,
`CALLOUTS.md`, and `FOOTNOTES.md`; the website is always one column
(`ARCHITECTURE.md` §8).

## 1. Page geometry

- **Trim size:** 7 × 9.1875 in (504 × 661.5 pt).
- **Margins:** `22mm 20mm 24mm` (top right/left bottom, per `book.config.ts`).
- Declared in exactly three places; if the trim size changes, update all three:
  1. `book.config.ts` → `page.width` / `page.height`
  2. `design/print.css` → `@page { size: 7in 9.1875in; }`
  3. `design/tokens.css` → `--page-width` / `--page-height`

The PDF build post-processes every page with `pdf-lib` to force MediaBox, CropBox,
BleedBox, TrimBox, and ArtBox to exactly 504 × 661.5 pt (Chromium rounds fractional
inch sizes).

## 2. Grid and wide material

- Body default: **two justified columns**, 6 mm gutter, no column rule.
- Column width is the measure in print (68ch equivalent; see `FONTS.md` §3).
- Hybrid rules:

| Element | Layout |
| --- | --- |
| Body prose, notes, display equations | Inside the column |
| Tables, code blocks | Span both columns automatically |
| Figures | Column width by default |
| `::: wide` block | Full-measure span |
| `::: wide page` block | Full measure, own page |
| `layout: single-column` chapter (frontmatter) | Whole chapter one column |
| `kind: references` chapter | Always single-column |

Decision rule: if the element is wide code, a large table, or a complex diagram, span
it; otherwise keep it in the column. If a diagram is unreadable at column width,
simplify or split it before reaching for `::: wide`.

## 3. Running heads

- **Top left:** chapter (or section) name — Barlow Condensed, uppercase, `--ink-muted`.
- **Top right:** page number — Minion Pro, tabular figures, `--ink-muted`.
- Mechanism: `string-set: chapter-title attr(data-running-title)`; frontmatter
  `runningTitle` overrides the visible title when it is too long.
- Suppressed on cover and part-title pages. **No page number at the bottom.**

## 4. Structure

Front matter order:

1. Cover (generated from `book.config.ts`)
2. Title page
3. Copyright
4. Table of contents
5. Preface

Body:

- A **part** opens on a new page with a large Roman numeral and the part title;
  running head suppressed.
- A **chapter** opens on a new page: label (`CHAPTER 1`) in Barlow Condensed uppercase
  muted gray, then the title (largest text on the page), then the `summary` in Minion
  Pro italic with a hairline below, then the body.
- **Back matter:** `kind: references` — single-column, unnumbered, in the TOC.

## 5. Table of contents

- Part names: uppercase, muted gray labels.
- Entries: chapter number, title, dotted leader, page number; references entries have
  no chapter number.
- Page numbers via Paged.js `target-counter`; hidden on screen.
- The TOC page is excluded from the EPUB navigation (the EPUB writer generates its
  own).

## 6. Numbering

- **Sections:** `##` numbered 1, 2, 3 … per chapter; `###` and deeper unnumbered.
- **Display equations:** (1), (2), … per chapter, number flush right.
- **Figures:** *chapter*.*n* (Figure 1.2); bold number, then caption.
- **Tables:** chapter-based, consistent with figures.
- **Notes (footnotes):** 1, 2, 3 … per chapter (`FOOTNOTES.md`).
- **Artifacts (website):** numbered like figures; pinpoint ids per
  `ARCHITECTURE.md` §9.

Numbers are generated by the build; never typed by the writer.

## 7. Mathematics, figures, code — spec pointers

- Math delimiters, macros, and constraints: `AGENTS.md` §2 and `book.config.ts`
  (`math.macros`). KaTeX HTML on web/PDF, MathML in EPUB.
- Figure formats, alt text, grayscale rule: `manuscript/STYLE.md` §12 and
  `COLOR.md` §3.
- Code fences, theme (`vitesse-light`), line-length limits: `manuscript/STYLE.md` §8
  and `FONTS.md` §2.
