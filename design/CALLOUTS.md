# CALLOUTS.md — Note and Callout Specification

How the seven note types render in every output (PDF, website, EPUB). Usage
discipline — when to use a callout and when not to — lives in
`manuscript/STYLE.md` §6.

## 1. Rendering model

Notes are part of the running text, not decoration:

- **Run-in bold label**, then the body. Example: **Theorem.** *Every range sum can be
  answered in constant time.*
- **No box, no background, no border, no icon.** Separation from body text comes from
  the label and spacing alone.
- The label is generated by the build from the note type; the writer never types it.
- A custom title may follow the note name: `::: definition Prefix sums`.
- Notes flow inside the text measure; they do not span columns or float.

## 2. The seven types

| Type | Purpose | Body style |
| --- | --- | --- |
| `definition` | Introduce a term or formal object | Italic |
| `theorem` | State a claim that is proved or justified | Italic |
| `example` | Work a concrete case (also used for exercises) | Upright |
| `note` | Context that is useful but not essential | Upright |
| `tip` | Practical advice, shortcut, contest habit | Upright |
| `warning` | A pitfall that costs WA / RE / TLE | Upright |
| `complexity` | Time and memory costs of the thing just built | Upright |

Constraints:

- No emphasis markup inside theorem and definition bodies (the body is already
  italic).
- No nesting of notes; no display math or code blocks inside a note.
- Syntax:

  ```md
  ::: definition Prefix sums
  The prefix-sum array of $a$ is the array $p$ with $p_i = a_0 + \dots + a_i$.
  :::
  ```

## 3. Reserved colors

Callouts have no background by default. The semantic tokens in `design/COLOR.md`
exist only for the rare case color supports the label:

| Token | Value | Reserved for |
| --- | --- | --- |
| `--warning` / `--warning-soft` | `#7a4a00` / `#f7f1e6` | `tip`, `warning` |
| `--danger` / `--danger-soft` | `#8a1f1f` / `#f8eded` | `warning` (hard constraint) |
| `--note` / `--note-soft` | `#333333` / `#f3f3f3` | `note` |

A color never replaces the label; grayscale output must lose nothing.

## 4. LaTeX target

Each note type maps to a matching LaTeX environment with run-in label styling:
`\begin{definition}[Title] … \end{definition}` etc. (conversion contract:
`AGENTS.md` §2).
